03 / AFTER미실행

입력 차단 경로

별도 허용 목록 설정에서 동일한 비정상 입력이 시작점에서 차단되는지 검증합니다.

실행 ID—실행 시각—
진단 입력미실행Before와 같은 비정상 옵션
모의 웹 세션미실행선행 차단 시 생성되지 않음
합성 자료 조회미실행차단 이후 단계는 실행되지 않음
내부 수신 기록미실행전송 요청이 시작되지 않음
관측 단계0개 확인
  1. 대응을 마친 뒤 After를 실행하면 차단 근거가 표시됩니다.

운영자 대응 대기

콘솔에서 대응 확인 ↗

화면 해석: Before의 탐지 경보는 자동 차단을 뜻하지 않습니다. After의 미실행은 앞 단계에서 입력이 차단되어 세션·조회·전송이 수행되지 않았다는 뜻입니다.

이 페이지는 해온카드 자체 진단 API 시나리오 전용입니다. 북웨이브 자체 공격과 PG 결제 연동 시나리오는 포함하지 않습니다.
