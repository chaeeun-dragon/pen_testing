가맹점 로그인과 정상 연결 진단

등록된 진단 대상에서 정상 응답을 확인합니다.

정상 업무

브라우저

  1. 가맹점 계정으로 로그인합니다.
  2. 등록된 진단 대상을 선택해 연결 상태를 확인합니다.
  3. 정상 상태와 응답 시간을 화면에 보여 줍니다.

터미널 결과

bash tools/haeon-diagnostic-lab.sh normal
cat evidence/runs/NORMAL-*/summary.txt

가맹점 세션과 회원 마이페이지의 회원 세션은 분리되어 있습니다.

“먼저 등록 대상에 대한 정상 연결을 확인합니다. 이 기능은 결제 승인이나 취소를 실행하지 않습니다.”

최초 진입과 제한 웹쉘 세션 · Before

진단 API 입력 처리에서 시작되는 공격 경로를 보여 줍니다.

공격 경로

시연자 조작

  1. Before 실행을 생성합니다.
  2. 가맹점 진단 API의 비정상 입력 처리 결과를 확인합니다.
  3. 같은 실행의 조회·전송 응답을 이어서 확인합니다.
bash tools/haeon-diagnostic-lab.sh before
RUN_DIR="$(find evidence/runs -maxdepth 1 -type d -name 'HAEON-DIAG-*' -printf '%T@ %p\n' | sort -nr | head -1 | cut -d' ' -f2-)"
RUN_ID="$(basename "$RUN_DIR")"
cat "$RUN_DIR/summary.txt" "$RUN_DIR/exfiltration.json"

화면에서 잡을 값

요청진단 API
결과ALERT
조회20건
전송수신 확인

실행 ID, 전송 ID, 수신 건수와 SHA-256을 함께 보여 줍니다.

“가맹점 진단 API에서 제한 세션이 만들어졌고, 지정된 자료의 조회와 내부 수신이 실행 ID로 연결됩니다.”

이벤트 기반 탐지와 증거 대조

성공 문구가 아니라 API와 수신기가 반환한 증거를 확인합니다.

방어자 확인

보여 줄 증거

  1. Before 응답과 세션 생성 이벤트
  2. 조회된 자료 20건과 수신 완료 결과
  3. 수신 기록의 같은 실행 ID·건수·SHA-256
  4. 탐지 이벤트에서 계산된 ALERT

화면 전환

터미널의 실행 폴더에서 요약, 수신 기록, 이벤트를 확인한 뒤 가맹점 화면으로 돌아옵니다.

세션 원문이 포함될 수 있는 attack-response.json은 촬영 화면에 열지 않습니다.

대응
