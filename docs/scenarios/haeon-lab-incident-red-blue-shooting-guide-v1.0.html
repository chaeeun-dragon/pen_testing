1

정상 진단

정상 업무가 먼저 동작하는 기준선을 남깁니다.

레드 시작

레드 역할

  1. 가맹점 포털의 로그인과 등록 대상 연결 확인을 짧게 촬영합니다.
  2. 공격 콘솔에서 정상 진단을 선택합니다.
  3. 실행 ID와 완료 상태를 확인합니다.

블루 역할

  1. 콘솔의 대상 준비 상태를 확인합니다.
  2. 시나리오 단계에서 가맹점 지원 계정 인증, 등록 대상 확인, 진단 요청 전송, 연결 진단 완료를 관찰합니다.
  3. 보안 이벤트에 경보가 없는 정상 기준선을 확인합니다.
“먼저 정상 가맹점 진단이 등록 대상에서 성공하는 기준선을 확인합니다.”
2

Before 공격 흐름

제한된 진단 입력 처리에서 모의 웹 세션이 만들어지는 흐름을 실행합니다.

레드 실행

레드 역할

  1. 공격 콘솔의 Before 공격 흐름을 선택합니다.
  2. 처리가 끝날 때까지 기다립니다.
  3. Before 실행 ID와 탐지 상태를 화면에 남깁니다.

콘솔은 미리 정해진 내부 흐름만 실행합니다.

블루 역할

  1. 탐지 상태가 탐지로 바뀌는지 확인합니다.
  2. 제한된 모의 웹 세션 생성과 자료 조회·전송 단계를 확인합니다.
  3. 이 Before 실행 ID를 대응 완료까지 같은 실행으로 유지합니다.
세션생성
자료20건
수신확인
판정탐지
“최초 진입은 해온카드 가맹점 진단 API입니다. 제한 세션은 지정 자료 조회와 내부 수신 흐름으로만 이어집니다.”
3

이벤트·수신 증거 관찰

성공 문구가 아니라 단계와 수신 결과를 근거로 판정합니다.

블루 관찰

레드 역할

  1. Before 실행 화면을 유지합니다.
  2. 시나리오 단계에서 제한 세션, 자료 조회, 내부 수신 결과가 끝났는지 확인합니다.
  3. 세션 값이나 원시 전송 본문은 열지 않습니다.

블루 역할

  1. 보안 이벤트에서 비정상 진단 입력, 세션 생성, 자료 조회, 전송 결과를 확인합니다.
  2. 실행 로그에서 처리 순서를 확인합니다.
  3. 수신 건수 20건과 SHA-256 일치, 관측된 탐지 결과를 촬영합니다.
콘솔 실행 이력은 콘솔의 실행 목록에서 다시 열 수 있습니다. 명령행 검증을 따로 실행한 경우에만 evidence/runs/에 별도 보관 파일이 생성됩니다.
4

운영자 대응

Before 실행의 관측 결과를 확인한 뒤 해당 세션을 폐기합니다.

블루 대응

레드 역할

  1. Before 실행을 선택한 상태로 기다립니다.
  2. 대응 이후에는 같은 실행으로 추가 조회·전송을 시도하지 않습니다.

블루 역할

  1. 대응 실행을 선택합니다.
  2. 사고 대응 완료 이벤트와 실행 상태 갱신을 확인합니다.
  3. 세션 폐기와 회원 보호 안내 등록을 촬영합니다.
실행대응 완료

안내등록
“자동 탐지 뒤 운영자가 대응을 실행했습니다. 이 실행에서 더 이상의 자료 조회나 내부 전송은 허용되지 않습니다.”
5

After 차단 검증

Before와 별도 실행으로 동일한 비정상 흐름이 통제에서 멈추는지 확인합니다.

레드 재시도

레드 역할

  1. 콘솔의 After 차단 검증을 선택합니다.
  2. 새 After 실행 ID가 생성된 것을 확인합니다.
  3. 차단 결과와 후속 단계 상태를 촬영합니다.

블루 역할

  1. 비정상 진단 입력 차단 이벤트를 확인합니다.
  2. 세션 생성, 자료 조회, 수신 전송 단계가 미실행인지 확인합니다.
  3. 필요하면 정상 진단을 다시 실행해 정상 업무가 유지됨을 확인합니다.
입력차단

6

회원 보호 안내

영향 회원과 비교 회원의 화면을 나누어 확인합니다.

블루 확인

영향 회원

  1. haeon01로 로그인합니다.
  2. 추가 확인 안내와 발생 시각을 확인합니다.
  3. 안내 확인 완료 상태를 기록합니다.

비교 회원

  1. haeon02로 로그인합니다.
  2. 동일 안내가 표시되지 않는지 확인합니다.
  3. 확인 완료는 읽음 기록임을 설명합니다.

촬영 마무리

한 화면에서 남길 결과는 정상 진단, Before 탐지와 수신 확인, 대응 완료, After 차단·미실행, 회원 보호 안내입니다.

bash tools/haeon-diagnostic-lab.sh reset
bash tools/network-port-security-check.sh

초기화 뒤에도 콘솔 이력은 남을 수 있습니다. 북웨이브·PG 통합은 이 해온카드 독립 시나리오와 섞지 않고, 전용 브랜치와 worktree에서 진행합니다.
